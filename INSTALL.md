# INSTALL

1. Загрузите файлы Jura CMS в корень сайта.
2. Убедитесь, что доступны для записи директории:
   - `storage/`
   - `storage/backups/`
   - `storage/updates/`
   - `uploads/`
   - `cache/`
   - `logs/`
3. Откройте сайт в браузере (`/`).
   - Если `storage/installed.lock` отсутствует, корневой роут автоматически перенаправит на `/install/`.
4. Пройдите шаг 1 установщика: проверка окружения (PHP, расширения, `vendor/autoload.php`, права записи).
5. Пройдите шаг 2: настройка базы данных (`DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`, `DB_PREFIX`) и проверка подключения через PDO.
6. Пройдите шаг 3: создание администратора (`site_name`, `admin_name`, `admin_email`, `admin_password`).
7. На шаге 4 завершите установку:
   - создаётся/обновляется `.env`;
   - создаются таблицы администраторов и настроек (если отсутствуют);
   - создаётся первый администратор;
   - записывается версия CMS в таблицу настроек;
   - только после успешного завершения создаётся `storage/installed.lock`.
8. После завершения установка перенаправляет на `/admin/login`.
9. Войдите в админку под email/паролем, указанными на шаге создания администратора.
10. После установки удалите или отключите каталог `/install/` в production.

## Важно

- Повторная установка заблокирована, если `storage/installed.lock` уже существует.
- `/install/` в этом случае показывает страницу «Jura CMS уже установлена», а POST-запросы установки игнорируются.
- Админка `/admin` требует авторизацию: без логина выполняется redirect на `/admin/login`.

# Jura CMS

Jura CMS после установки через `/install/` создает базовый набор таблиц CMS: пользователи/группы/права, страницы, посты, товары, меню, медиа, маршруты, редиректы, настройки, миграции и журнал действий.

## Авторизация админки

Админка защищена авторизацией (`/admin/login`), сессией и middleware для всех `/admin/*` страниц.

## Пользователи и группы

Используются `jura_users` и `jura_user_groups` (вместо `admins`). Права задаются через `jura_permissions` + `jura_group_permissions`.

## Модули

Структура модуля, версионирование (semver) и правило именования ZIP-архива для загрузки через `/admin/modules` — см. [`docs/modules.md`](docs/modules.md).

# Jura CMS

Jura CMS использует `config.php` в корне сайта как основной конфиг.

- `.env` не является обязательным и не используется установщиком.
- Установка выполнена в стиле классических CMS: открываете сайт и проходите `/install/`.
- После установки рекомендуется удалить или отключить каталог `/install/`.
